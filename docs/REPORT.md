# Отчёт: лендинг «Ассистент преподавателя разыгрывает призы»

Макет: Figma, файл «Лендинги (Ready For Dev)», фрейм «Макет лендинга» (node 1524:13629).
Сайт: https://sobavk-code.github.io/teacher-prizes/ (статика: HTML, CSS-переменные, JS).

## Что готово и как проверено

Метрика: полностраничный скриншот сайта сравнивается с полностраничным экспортом макета попиксельно (`pixelmatch`, порог цвета 0.1). Показатель diff, % равен доле отличающихся пикселей. Порог готовности: не более 5% на ширину.

| Ширина | diff built↔Figma | Размер страницы (сайт / макет) | Итог |
|---|---|---|---|
| 1728 | 1.39% | 6812 / 6812 | PASS |
| 1920 | 1.72% | 6812 / 6812 | PASS |
| 360 | 3.36% | 8926 / 8924 | PASS |
| 1440 | 5.74% | 6855 / 6854 | FAIL (баннер, расположение объектов) |
| 1024 | не сверстано | | нет |
| 768 | не сверстано | | нет |

Для каждой проверенной ширины: один `h1`, нет горизонтальной прокрутки страницы, битых картинок нет.

## Сравнение на 1920: где остались расхождения

Картинки: `docs/diff-1920/` (макет, сайт и различия рядом, лучшие и худшие полосы, увеличенный подарок).
Автоматический отчёт сравнения: `docs/compare-1920-auto-report.md`.

- Текст везде совпадает по содержанию, но смещён на 1–2 px по вертикали, отсюда тонкая окантовка в diff.
- Главное реальное расхождение: декор FAQ (подарок и знак вопроса). В макете размытие прогрессивное (резко сверху, мягче к низу), у нас равномерный `blur()`. Предложение: заменить маской-градиентом.
- Картинки баннера на 1920 и 1440 собраны из скриншотов Figma (объекты) и фона баннера, а не экспортированы по слоям.

## Эталонный лендинг (https://edu-assist.ru/teacher)

Сравнение с ним некорректно: это общий лендинг продукта «Рабочее пространство педагога», а не страница акции с призами.
Цифры (built↔reference 24.32%, reference↔Figma 24.4% на 1920, 93 фразы есть у эталона и нет у нас) относятся к двум разным страницам.
Вывод «где ручная вёрстка отклоняется от макета» не сделан: нужна ссылка на страницу акции.

## Что не сделано

- Вёрстка 1024 и 768 (скриншоты макета сохранены, секции имеют другие высоты и перестроены).
- Доведение 1440 до PASS.
- Сравнение с правильной эталонной страницей акции.
- Все ссылки в вёрстке пока `href="#"`.
- Мобильная версия содержит ручные переносы строк (`<br class="m">`), скопированные со скриншота макета.
